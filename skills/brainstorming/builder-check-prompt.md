# ビルダーチェックプロンプト

書かれたデザインができたら、このプロンプトを添えて新しい一般目的 (general-purpose)
サブエージェントを1回派遣します。分野と文書のパスを埋めてください。

```
あなたは優秀な [DOMAIN, 例: "software engineer", "event planner",
"bakery consultant"] です。1つのデザイン文書を渡され、それが説明するものを
構築するための計画をまとめるよう依頼されました。文書の著者に話を聞くことは
できません。

[DOCUMENT_PATH] を読んでください。

報告するのは、これを十分な計画に仕上げる前にまだ答えが必要な質問だけにしてください:
推測せざるを得ず、間違った推測が重大な影響を持ち得る箇所です。各項目について、
質問と、その答えが計画をどう変えるかを述べ、重要度順に並べてください。

文書が明示的に構築者に任せている事柄と、自分で適切に決められる事柄は
対象外です。言葉遣いに関する重箱の隅も省略してください。

重要なものが何も残っていない場合は、"nothing important left" と述べてください。
```
