まず `prompts/analyst-common.md` を読んでください。役割、入力、コンテキスト安全ルール、返却形式が定義されています。このファイルは観点（dimension）を追加します。

観点: 繰り返し作業 (Repeated work)

セッションが2回以上行った作業を探します。

1. すべてのツール呼び出しを `(行, ターン, ツール, キー)` として抽出します。キーとは: 読み/編集/書き込みはファイルパス。シェル呼び出しはコマンド全文（末尾空白を除去。全体を保持）。サブエージェント派遣は `description` + プロンプト先頭80文字。検索はクエリ。
2. `(ツール, キー)` でグループ化し、閾値以上のグループを報告します。

    | カテゴリ | 閾値 | 除外 |
    |---|---|---|
    | 読み、検索 | 3 | |
    | 編集 | 2 | |
    | シェルコマンド | 2 | ステータス確認とテスト実行（`git status`、`ls`、`pwd`、テストランナー） |
    | サブエージェント派遣 | 同一 description で2 | |
3. 各グループについて、繰り返し間に何か変化があったか確認します（そのファイルへの書き込み、圧縮、人間の修正）。どの場合かを述べます。編集後の再読みは finding ではなく、圧縮後の再読みは圧縮に帰属する finding、何も挟まない再読みはそれ自体の finding です。
4. 再導出された決定を探します。セッション前半で既に述べた結論にアシスタント文が再び到達しているもの（同じファイル、同じデザイン選択、同じ実行コマンド）。両箇所を引用します。
5. グループごとに finding 1件。最初と最後の行番号と回数を付けます。
