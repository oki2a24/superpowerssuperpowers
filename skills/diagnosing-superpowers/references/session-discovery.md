# セッション履歴の発見 (Discover the session history)

この環境で利用可能なツールと情報を使い、人間パートナーが指名したセッションを解決します。知識は手がかりになります。結果は実際の履歴に照らして検証します。

ハーネスが公開するセッション ツール、設定済みストレージ、ローカルヘルプ、ドキュメント、または境界付きファイルシステム検査を使用します。内容を読む前にファイルを測定し、context-safety.md に従います。環境が指す場合はアーカイブやインデックスを検査します。使用可能なパスが支給されていれば再探索は不要です。

利用可能なセッション id、作業ディレクトリ、タイムスタンプ、一致する会話内容で身元を確認します。新しさだけでは確認になりません。要求されたセッションをその子や無関係候補と区別します。利用可能な証拠で区別できない場合は、不足する識別事実を求めます。

各ファイルシステムソースについて、環境から完全な絶対パスを取得します（ホームディレクトリ省略形と変数を展開）。ケース記録と人間パートナーへの発見回答に同じパスを使用します。

要求された調査に必要な記録意味を、観測記録やドキュメントから確立します。人間メッセージと注入メッセージ・ツール結果・親エージェント派遣を区別します。ツール呼び出しと結果を対応付けます。合計計算前に使用量カウンタ意味を確立します。他ハーネスの形式を推測したり、欠落フィールドをゼロに変えたりしてはなりません。

正確なソース、関連フィールド意味、裏付け記録位置、関連セッション、棄却した妥当候補、未解決情報をケースファイルに記録します。後続の読み手は発見を繰り返さずその記録を使用します。履歴が欠落・到達不能・曖昧な場合、具体的な制限を述べ、不足するパス・出力・識別詳細を求めます。
