# 同じ形の小さな作業をまとめる

superpowers:subagent-driven-development の一部。

**同じ形の小さな作業をまとめる。** 計画が、同じ種類の小さく独立した編集 — 同じ1行の修正、定数の変更、ファイルをまたぐ同種のフィールド追加 — を複数のタスクとして列挙しているときは、タスクごとに1つのサブエージェントを派遣しません。すべてのファイルとその変更を列挙した **1つ** の派遣概要（dispatch brief）を作成し、その一括全体を単一のサブエージェントに送り、その差分を一括単位でレビューします。独自の判断、独自のテスト、独自のレビュー範囲を必要とする作業についてのみ、タスクごとの派遣を確保します。
