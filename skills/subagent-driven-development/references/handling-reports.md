# レポートが DONE 以外のときの処理

superpowers:subagent-driven-development の一部。

**DONE_WITH_CONCERNS:** 実装者は作業を完了しましたが、懸念にフラグを付けています。まず懸念を読みます。正確性または範囲に関する懸念ならレビュー前に解決し、単なる観察（例「このファイルが大きくなっている」など）なら記録してレビューへ進みます。

**NEEDS_CONTEXT:** 実装者に提供されていなかった情報が必要です。不足情報を補い、再派遣します。

**BLOCKED:** 実装者がタスクを完了できません。行き詰まりの原因を見極めます:
1. コンテキストの問題なら、より多くの文脈を補って同じモデルで再派遣する
2. より高度な推論が必要なら、より能力の高いモデルで再派遣する
3. タスクが大きすぎるなら、より小さな断片に分割する
4. 計画そのものが誤っているなら、修正を裁定して台帳に記録し、その裁定を派遣に持たせて再派遣する

エスカレーションを無視したり、変更なしで同じモデルに繰り返させたりしません。実装者が行き詰まったと言ったなら、何かを変える必要があります。
